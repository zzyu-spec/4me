# 홈 날씨 복구 처리

- 현재 날씨는 기존 Open-Meteo, 지역 검색은 기존 Nominatim/기상 지오코딩을 유지한다. API 키·새 서버·새 유료 서비스는 추가하지 않는다.
- `weatherRegion` 및 모든 사용자 기록 형식은 그대로 보존한다. 공개 예보 응답만 별도 localStorage `harugyeol-weather-cache-v1`에 좌표별 최대 4개 저장한다. 정상 캐시는 15분 재사용하며, 실패 시 최근 6시간 내 응답만 확인 시각/업데이트 실패 문구와 함께 표시한다. 오래된 예보를 최신으로 가장하지 않는다.
- 인터넷 재연결은 자동 재조회, 화면 복귀는 캐시·유효기간을 확인한다. 중복 요청은 공유하고 실패 후 일반 재조회는 1분 대기한다. 수동 재시도는 허용하되 429 및 Retry-After는 재연결/수동 요청도 대기 시간을 지킨다.
- 429 조회 제한, 5xx 제공 서비스 오류, 시간 초과, 잘못된 응답, 오프라인을 구분해 표시한다. 상세 서비스 응답 코드는 재시도 버튼 title에 남긴다. 사용자 검색어나 정확한 좌표를 오류 안내에 출력하지 않는다.

확인된 앱 문제는 **초기 조회 실패 후 네트워크 복귀 시 자동 복구가 없었던 것**과 실패 이유가 가려졌던 것이다. 특정 사용자의 당시 실패가 제공 서비스 장애/요청 제한/기기 연결 중 무엇인지는 단정할 수 없다. 이 작업 환경의 외부 날씨 API 직접 요청은 네트워크 정책 403으로 차단되었으며, 이를 실제 사용자 환경의 API 장애로 해석하지 않았다.

검사: `tools/weather-recovery.test.cjs`와 `tools/weather-neighborhood.test.cjs`(SDK/제공 서비스 모형). 마지막 응답 보존/새로고침/실패 후 재연결/중복 방지/429 대기/잘못된 응답/모바일 경계/지역 및 기존 기록 보존을 확인한다. 실제 제공 서비스나 iPhone 실기기 검증은 별개다.
