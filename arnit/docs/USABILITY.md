# 입력·분류·모바일 사용성 개선

## 사용자 요청 반영

- 무드보드 제목은 선택 사항입니다. 비워두면 `새 무드보드`, `새 무드보드 2`처럼 구분 가능한 임시 이름을 부여하며 나중에 수정할 수 있습니다. 임시 이름으로 저장한 보드를 편집할 때 입력창은 비어 있습니다. 다른 목록의 제목 필수 조건은 유지합니다.
- 홈의 ‘최근 저장한 취향’ 섹션과 버킷리스트 행의 ‘언젠가 나에게 남길 경험’ 문구를 제거합니다. 저장한 기록과 목표 날짜/완료일은 지우지 않습니다.
- 무드보드 기본 카드에는 저장 날짜를 표시하지 않고 상세 보기에서 확인합니다.
- 새 취향 컬렉션은 카테고리를 선택합니다. 그 안에서 새 항목은 해당 카테고리로 저장되고, 기존 항목 연결도 같은 카테고리만 제시합니다. 기존의 분류 없는 컬렉션은 유지합니다. 기존 기록을 임의로 다른 분류로 바꾸지 않으며, 기록이 다른 분류에 속하면 컬렉션 분류 변경을 거절하고 설명합니다.
- 카테고리 이름 변경/삭제 시 연결된 컬렉션의 분류도 함께 갱신합니다. 취향 항목의 분류를 바꾸는 편집 화면에서는 맞지 않는 컬렉션의 연결 해제를 알립니다. 항목 자체를 삭제하지 않습니다.

## 모바일 폼

- 일반 입력·선택·날짜·색상·파일 입력칸 높이 40px, 설명 입력은 모바일 72px로 정리합니다.
- 두 칸 레이아웃은 `minmax(0,1fr)`로 같은 너비를 사용합니다. 네이티브 날짜 입력의 최소 너비도 제한하고 350px 이하에서는 한 칸으로 배치합니다.
- 모달은 헤더/스크롤 본문/푸터를 분리해 긴 입력 화면에서 영역이 겹치지 않도록 합니다.
- 무드보드의 표지·팔레트·공개 범위는 펼칠 수 있는 추가 설정으로 묶습니다.

## 접근과 버그 수정

- 서랍 상세 화면의 상단 `+`는 그 서랍의 항목 편집기를 바로 엽니다. 스크린리더용 동작 이름도 현재 화면에 맞춥니다.
- 새 이미지 기록의 제목이 비어 있을 때 파일 이름으로 채웁니다. 사용자가 입력한 제목을 임의로 바꾸지 않습니다.
- `/`, Ctrl/Cmd+K로 통합 검색에 접근합니다. 글 입력 중, 한글 조합 중, 모달, 로그인 전 화면에서는 잘못 가로채지 않습니다.
- 필터·즐겨찾기 저장 후 키보드 초점이 유지되며 모달을 닫으면 적절한 위치로 돌아갑니다.
- 항목 편집/서랍 연결 변경이 기존 카드 순서를 뒤로 밀던 문제를 수정합니다.
- 이미지 제거 체크 뒤 새 파일을 고르거나 이미지 URL을 바꿀 때 새 이미지가 적용되도록 합니다.
- 이전 모달의 닫기 이벤트가 새 이미지 미리보기의 정리 작업을 건드리지 않도록 합니다.
- 계정이 바뀐 뒤 도착한 사진 선택/저장 완료 이벤트가 새 계정의 편집 화면에 영향을 주지 않도록 합니다.

## 검증

`tests/usability.cjs`: 제목 생략/임시 이름 유지/이름 수정, 홈 섹션 제거, 날짜 상세만 표시, 빠른 추가/파일명 제목, 사진 교체/URL 교체, 기존 순서 보존, 초점/검색, 카테고리 제한, 기존 데이터 유지, 폼 너비/섹션 분리, 기본 문구 삭제.

`tests/forms.cjs`: 이미지·취향·상품·목표 편집기를 320/390/430/768px에서 검사합니다. 일반 입력칸 높이·폭·가로 넘침과 헤더/본문/푸터 분리, 모바일 설정 스크롤을 확인합니다.

기존 `archive.cjs`, `interactions.cjs`, `accounts.cjs`로 마이그레이션/백업/콜라주/오프라인/다중 목표/로그인 저장 회귀를 검사합니다. 계정 검사는 테스트 SDK를 사용하며 운영 사용자 데이터에는 접근하지 않습니다.

데이터 스키마 버전·기존 키·계정별 저장소·Firebase 규칙은 변경하지 않습니다. `untitled`, 컬렉션 `category`는 선택적 그룹 속성으로 저장합니다.

## 제목 생략 보완

무드보드 자체의 이름뿐 아니라 이미지·링크·메모·색상 카드의 제목도 생략할 수 있습니다. 저장 호환성을 위해 내부 표시 이름은 파일명·메모 첫 줄 또는 기본 문구로 채우며, 사용자에게 제목 입력을 요구하지 않습니다. 기존 기록과 목록의 ID는 유지합니다. 제목을 비운 뒤 실제 파일/URL/메모 저장, 편집, 새로고침, 오프라인 저장을 `tests/optional-titles.cjs`로 확인했습니다. 버전이 붙은 진입 스크립트·모듈과 캐시 재검증/오프라인 경로 대체로 예전 코드가 남는 상황도 보완했습니다.

## 일반 체크리스트
- 버킷리스트와 독립적인 checklist 목록과 task 항목을 기존 groups/items에 추가합니다. 기존 기록을 변환하거나 삭제하지 않습니다.
- 목록 생성·편집·복제·보관·휴지통 복구와 통합 검색, 계정 동기화 및 전체 백업을 재사용합니다.
- 상세 화면에서 Enter로 빠른 추가, 완료 체크/취소, 항목 수정·삭제가 가능합니다. 완료 항목은 목록에 남습니다.
- 기존 schemaVersion 3의 선택 가능한 유형을 확장하며 Firebase 규칙·백엔드 변경은 필요 없습니다. 구버전 탭에서는 새 유형을 읽을 수 없으므로 최신 버전으로 새로고침해야 합니다.
- 모바일 메뉴 7개에 맞춰 너비를 조정하고 기존 작은 팝업과 배경 터치 닫기를 유지합니다.

## 컬렉션 하위 분류
- 컬렉션의 선택 필드 sections에 분류 ID·이름·항목 연결을 저장합니다. 기존 컬렉션과 항목의 원본은 변경하지 않고 미분류로 표시합니다.
- 컬렉션별 분류 생성·이름 변경·삭제, 전체/미분류/분류 필터, 저장 시 분류 선택, 상세 화면에서 이동을 지원합니다.
- 분류 삭제는 항목을 삭제하지 않습니다. 서랍 연결을 해제하면 해당 서랍의 하위 분류 연결도 정리합니다.
- 기존 계정 동기화·전체 백업을 재사용하며 Firebase 규칙 변경은 없습니다. 브라우저 탭과 설치 이름은 아르닛으로 통일합니다.

## 화면 테마
- 밝은 모드/다크모드/기기 설정에 맞추기를 지원합니다. 상단 달 버튼으로 즉시 전환하고 설정에서 세 가지 방식 중 선택합니다.
- arnit-theme 로컬 설정만 저장하고 계정 데이터와 백업 형식은 변경하지 않습니다. 초기값은 OS 설정이며 페이지 스타일 적용 전에 테마를 결정합니다.
- 탭 간 설정 및 OS 테마 변경을 반영하고 사진·사용자 색상칩은 변환하지 않습니다.
- 시스템/수동 전환·재접속 유지·모바일 넘침·어두운 입력창·저장 검사를 통과했습니다.
