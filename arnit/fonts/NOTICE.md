# Arnit UI font

`ArnitUI.woff2` is a UI and Latin character subset of Pretendard Variable 1.3.9
by Kil Hyung-jin, distributed under the SIL Open Font License 1.1 (see OFL.txt).
The modified font family has been renamed **Arnit UI** in accordance with the
reserved font name provisions. No paid or externally hosted font service is used.

The subset covers the application's Korean UI text and Latin characters. Other
user-entered characters fall back to the device's native Korean/system font.

Upstream: https://github.com/orioncactus/pretendard
Source: packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2
