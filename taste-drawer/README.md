# 취향 서랍

좋아하는 것과 앞으로 경험하고 싶은 것을 함께 정리하는 개인 취향 아카이브입니다.

- 장소·색·음악·음식·영화·책·문구·제품·기타 분류
- 나의 취향 / 해보고 싶어요(버킷리스트) 상태
- 기록 추가·수정·삭제, 사진·메모·태그·링크, 검색·즐겨찾기
- JSON 백업 및 불러오기, 모바일 화면 지원

## 실행

빌드나 설치 없이 `index.html`, `style.css`, `app.js`를 정적 서버로 실행합니다.

```sh
python -m http.server 8000
```

저장소 루트에서 실행한 경우 `http://localhost:8000/taste-drawer/`를 열어주세요.
GitHub Pages가 저장소 루트를 배포한다면 `/taste-drawer/` 경로로 접근할 수 있습니다.

## 데이터

기록과 사진은 현재 브라우저의 localStorage에 저장됩니다. 서버 동기화는 제공하지 않습니다.
다른 기기·브라우저·사이트 주소로 이동할 때는 기록 백업과 불러오기를 사용하세요.
