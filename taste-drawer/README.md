# 취향 서랍 · 웹앱

좋아하는 것과 앞으로 경험하고 싶은 것을 함께 정리하는 개인 취향 아카이브입니다.

**배포 주소:** https://zzyu-spec.github.io/4me/taste-drawer/

`main` 브랜치의 `taste-drawer/` 변경은 기존 GitHub Pages 배포에 자동 반영됩니다.
기존 4me 앱은 저장소 루트에 유지됩니다.

## 웹앱으로 사용

- iPhone / iPad: Safari로 배포 주소를 열고 **공유 → 홈 화면에 추가**를 선택합니다.
- Android / Chrome: 배포 주소의 **설정 → 홈 화면에 설치하기**를 선택하거나 브라우저의 설치 메뉴를 사용합니다.
- 앱 이름, 전용 아이콘, 독립 창 실행을 위한 웹앱 매니페스트를 제공합니다.
- 한 번 온라인으로 열어 앱 파일이 저장되면 오프라인에서도 기록 열람·추가·수정이 가능합니다.
- 서비스 워커와 캐시는 `taste-drawer/` 범위만 사용하며 기존 4me 캐시를 삭제하지 않습니다.

## 기능

- 장소·색·음악·음식·영화·책·문구·제품·기타 분류
- 모아보기 / 버킷리스트 / 즐겨찾기 하단 메뉴와 빠른 기록 버튼
- 기록 추가·수정·삭제, 사진 미리보기·제거, 메모·태그·링크
- 카테고리·검색·정렬, 즐겨찾기, 예시 기록만 삭제
- 기존 브라우저 기록(`taste-drawer-v1`) 유지
- JSON 백업 및 불러오기

## 데이터

기록과 사진은 현재 브라우저의 localStorage에 저장됩니다. 서버나 GitHub로 기록을 전송하지 않습니다.
기기·브라우저 변경이나 사이트 데이터 삭제 전에 설정에서 백업해주세요.
백업 불러오기는 기록 ID를 기준으로 병합하며, 같은 ID가 있으면 백업의 값을 적용합니다.
브라우저/OS에 따라 설치한 웹앱의 저장 공간이 브라우저와 별개일 수 있으므로, 설치 후 기록이 보이지 않으면 백업 파일을 불러오세요.

## 로컬 실행

빌드나 설치가 필요하지 않은 HTML/CSS/JavaScript 앱입니다.
저장소 루트에서 다음 명령을 실행한 후 `http://localhost:8000/taste-drawer/`를 엽니다.

```sh
python -m http.server 8000
```

아이콘 원본은 `icon.svg`, 홈 화면용 PNG 파일은 `icons/`에 있습니다.
`manifest.webmanifest`의 시작 주소·범위는 현재 폴더를 기준으로 합니다.
서비스 워커의 앱 자산 목록을 바꿀 때는 `sw.js`의 캐시 버전도 갱신해주세요.
