# arnit. 아르닛 — 나의 취향 기록장

기존 취향 서랍을 확장한 개인 이미지·취향·소망 아카이브입니다.

**배포:** https://zzyu-spec.github.io/4me/taste-drawer/

기존 주소와 웹앱 ID는 유지합니다. `main`의 `taste-drawer/` 변경은 기존 GitHub Pages에서 자동 배포됩니다. 루트 4me 플래너는 그대로 유지하며, 기존 Firebase에 아르닛 전용 계정 저장 규칙을 추가합니다.

## 기능

- 무드보드: 여러 보드 생성/편집/복제/보관/휴지통/정렬, 이미지 콜라주 표지와 Masonry 그리드
- 이미지 업로드, 이미지 URL, 웹페이지 링크, 텍스트·색상 카드. 여러 보드에 같은 항목 연결
- 콜라주: 포인터 이동/리사이즈, 키보드 및 숫자 편집, 앞뒤 배치, 그리드와 별도의 저장·복원
- 팔레트: 직접 색 지정 및 기기 이미지에서 대표 색 추출
- 취향 컬렉션: 사용자 카테고리, 감상·평점·태그·연결 보드
- 다중 위시리스트: 가격(직접 입력)·브랜드·우선순위·구매일·완료 보관
- 다중 버킷리스트: 기간·달성률·목표일·공유 목표·완료일·후기·완료 사진
- 아카이브: 완료 목표/구매 상품/보관한 무드보드와 컬렉션, 날짜·유형 필터
- 별도 휴지통과 복원, 전체 유형 통합 검색, 공통 태그, 즐겨찾기
- 전체 JSON 백업/불러오기(이미지·소속·콜라주 포함), 이전 백업 호환
- 설치형 웹앱, 로컬 무료 폰트, 오프라인 열람·추가·수정

## 저장과 호환

하루결의 Firebase 이메일 계정으로 로그인합니다. 사진·기록은 계정별 서버 경로에 저장하고, 오프라인과 저장 실패에 대비해 기기에도 보관합니다. **서버 규칙 게시가 선행되어야 계정 저장이 성공합니다.** [Firebase 적용 안내](docs/ACCOUNTS.md)를 확인해주세요.

브라우저 IndexedDB `taste-drawer-library-account-<uid>`에 메타데이터와 이미지 blob을 저장합니다. 동일 이미지 파일은 SHA-256 키로 중복 저장을 방지하고, 여러 서랍에서 항목 ID를 공유합니다. 같은 목표를 여러 목록에 넣으면 완료 상태도 공유됩니다.

기존 `localStorage['taste-drawer-v1']`는 **지우거나 덮어쓰지 않습니다**. 최초 로그인 후 기존 기기 기록을 연결할 계정을 확인한 뒤 사용자 기록을 복사합니다. `sample:true` 예시는 실제 사용자 데이터로 생성하지 않습니다. 기존 ID·날짜·분류·즐겨찾기·사진·메모를 유지합니다. 이전 `wish`는 ‘기존 버킷리스트’로, `love`는 ‘이전의 취향 기록’으로 연결합니다.

복사나 저장에 실패하면 원자적 트랜잭션을 취소하고 오류를 표시합니다. 다른 탭의 변경은 revision 검증으로 덮어쓰지 않습니다. 새로운 전체 백업과 예전 `{records: [...]}` JSON 백업 모두 불러올 수 있으며, 같은 ID는 백업의 값으로 바뀐다는 확인 후 병합합니다.

사이트 데이터 삭제·기기 교체 전에 설정에서 **전체 백업**을 다운로드해주세요. 설치 앱과 브라우저 저장소가 분리되는 OS에서는 백업 파일로 옮길 수 있습니다. 휴지통 항목도 백업과 복원 대상입니다. 영구 삭제/자동 초기화 기능은 없습니다.

## 공개 범위와 한계

- 이메일 인증된 사용자 본인의 비공개 계정 보관함입니다. 공개 보드 공유는 제공하지 않습니다.
- 4me의 인증 SDK·프로젝트를 재사용하며 아르닛은 전용 Firestore 경로에 저장합니다. 기존 플래너 문서를 읽거나 수정하지 않습니다.
- 계정 저장 성공 여부는 상단 상태로 구분합니다. 권한·연결·용량 오류가 있으면 기기 기록은 유지하고 서버 저장이 필요함을 표시합니다.
- 웹페이지 메타데이터 자동 추출과 실시간 상품 가격 추적은 하지 않습니다. 이미지·제목·가격을 직접 입력합니다.
- 외부 이미지 URL은 원본 사이트 정책·오프라인 상태에 따라 불러오지 못할 수 있습니다. 직접 올린 이미지는 기기에 보관되고 백업에 포함됩니다.

## 설치

- iPhone/iPad: Safari → 공유 → 홈 화면에 추가
- Android/Chrome: 설정의 설치 안내 또는 브라우저의 앱 설치 메뉴

## 개발과 검증

빌드·런타임 의존성이 없는 HTML/CSS/ES module 앱입니다. 저장소 루트에서:

```sh
python -m http.server 4193
```

`http://localhost:4193/taste-drawer/`를 엽니다. 실제 로그인에는 Firebase 프로젝트와 게시된 규칙이 필요합니다. Node.js, Playwright와 Chromium이 있는 테스트 환경에서는 별도의 모형 서버를 실행합니다:

```sh
node taste-drawer/tests/server.cjs
# 다른 터미널에서 실행 (테스트 전용 4194 포트)
node taste-drawer/tests/archive.cjs
node taste-drawer/tests/interactions.cjs
node taste-drawer/tests/accounts.cjs
```
